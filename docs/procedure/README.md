# Procedures Index

How to carry out a recurring act in this repository: the files to open, the order of the acts, the commands, and what the host does. A procedure states no rule; where an act is governed, it cites the convention that governs it, and `AGENTS.md` §What this file outranks places this layer below the conventions.

## Files

| File | Covers |
|---|---|
| `review-a-pull-request.md` | Reviewing a pull request, from choosing the conventions to read to posting the verdict |
| `anchor-a-claim.md` | Turning a claim in a document or a GitHub artifact into one a reader can check |
| `dispatch-a-worker.md` | Starting a worker through Orca, binding its role, waiting on it, and releasing it once it settles |
