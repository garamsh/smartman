# Web admin

The web's `admin` feature: the admin area at `/admin`, its gate, sections, actions and reads. The role, the audit log and the functions behind it are [`server.md`](server.md)'s.

## Current decisions

### Area

- Operators run the service from `/admin`, in the `(shell)` route group, on the web only; the app has no admin screen ([ADR 0070](adr/0070-run-the-service-from-a-web-admin-area-whose-role-and-audit-log-live-in-the-database-and-whose-every-read-and-write-is-checked-there.md)). Its layout, `web/src/app/(shell)/admin/layout.tsx`, renders nothing until the server's `is_admin` answers, inside a Suspense boundary with an empty fallback: an admin then sees the section menu and the page; anyone else gets the not-found page, streamed as a deck that does not exist is; a server that cannot answer gets the error page. The area's pages set no metadata, so no title names it, and no link elsewhere leads to it.
- The role and every check live in the database ([`server.md`](server.md) §Admin area): every read and write is one of the server's admin functions, called with the user's session and the publishable key, and each refuses a caller who is not an admin. The web holds no service-role key and no admin's email or id.
- Each section's page is headed by its name in the menu, the overview "개요" (#326).
- The section menu, "관리 메뉴", a navigation landmark with the current section marked `aria-current="page"`: 개요, 신고, 공개 덱, 사용자, 요금제, 프롬프트, 관리자 and 작업 기록.
  - **개요** (`/admin`): users in total and new in the last 7 and 30 days; users who studied today and in the last 7 days, study days from 04:00 in the cookie's zone through `study`'s `studyDayStart`; and under 사진 추출 the last 30 UTC days of photos from `admin_extraction_breakdown` ([ADR 0074](adr/0074-chart-the-overview-s-photos-and-cost-by-day-plan-model-and-prompt-version-with-recharts-each-chart-an-image-named-by-a-sentence-beside-a-table.md)): today's, 7 days' and 30 days' photos and estimated cost; each day's photos as bars and cost as a dashed line; each day's cost stacked by plan and by model, each series in its own ink pattern with a legend; and the photos and cost by prompt version, each linked. Each photo is costed at its model's measured cost from `web/src/features/admin/model-costs.ts`, a photo counted before calls were recorded (기록 전) at the model of Free's current version, and one a never-measured model served is counted apart and named. Each chart is one `img` named by a sentence of its totals, followed by a table of every value.
  - **신고** (`/admin/reports`): the reported decks, the latest report first, each with its owner, report count, reasons in the app's words, state (공개, 비공개, 숨김, 삭제됨) and actions.
  - **공개 덱** (`/admin/decks`): every public deck, searched by name through the address's `q`, with its owner, cards, copies ("가져오기 n회"), reports and actions; `/admin/decks/[id]` opens any deck read-only, its cards' sides in two columns, and is not found for an id that is no deck's ([ADR 0072](adr/0072-suspend-a-user-through-supabase-auth-s-ban-and-restrictive-write-policies-remove-a-public-deck-from-sharing-for-good-and-read-any-deck-in-the-admin-area.md)). A public deck not yet removed offers "공유에서 영구 삭제", which asks for a reason; a removed deck shows the reason and the day instead.
  - **사용자** (`/admin/users`): the search by email as the admin types, 250 ms after the last keystroke, starting from the address's `q`: the shown results stay until the next arrive, an answer to an older query is dropped, a `status` region reads the count out, and "더 보기" adds the next 20 ([ADR 0072](adr/0072-suspend-a-user-through-supabase-auth-s-ban-and-restrictive-write-policies-remove-a-public-deck-from-sharing-for-good-and-read-any-deck-in-the-admin-area.md)). The search lives in the address (#326): each search, and each page "더 보기" adds, replaces it with `?q=` and `&page=` through the browser's `history.replaceState`, which Next.js keeps its router in step with and which reads nothing again; an address with `q` opens with its pages through `page`, a whole number of up to three digits, read on the server, so going back from a user's page shows the same results. The address carries only the query; every read is still checked in the database. `/admin/users/[id]` is a user read-only: the sign-up date, the last study, decks and cards, the photos counted in the period of the user's plan version against its limit, "이번 달 사진 추출" on a monthly plan and "오늘 사진 추출" otherwise, both in Asia/Seoul, whether the user is an admin, the user's plan, the user's public decks, and under "덱" every live deck of the user, private ones too, each opening the deck. Under "요금제" the plan shows with its model and terms, such as "한 달 10장" or "무제한 (하루 1000장까지)", and the grant behind it, its granter and its last day; a form puts the user on 프로, or on 맥스 until the end of a chosen day's study day in the admin's zone, or without an end, on the version a user subscribing now takes; and "무료로 되돌리기", asked first, removes the grant. Under "이용 정지", "이용 정지" asks for a reason and suspends the user, and a suspended user shows "정지됨" with the reason, when and by whom, and "정지 해제". Nothing here edits or deletes an account or a deck.
  - **요금제** (`/admin/plans`): a section per plan, 무료, 프로 and 맥스 ([ADR 0097](adr/0097-give-each-plan-versions-of-its-terms-with-a-start-free-10-a-month-pro-100-a-day-and-max-unlimited-to-1000-a-day-each-grant-taking-the-latest-at-its-monthly-renewal.md)):
    - the terms a user subscribing now takes, as "지금 가입하면 한 달 10장 · model", with the eval's measured cost per photo beside a measured model;
    - a form, "새 버전", starting from those terms: the quota (한 달에, 하루에, or 무제한 with its fair-use cap a day), the number of photos, the model, the start, 00:00 Asia/Seoul on the day chosen or now when it is empty, and whether existing users take it from its start rather than at their renewal on the 1st, which only a change in their favour may;
    - every version, the latest start first, with its terms, model, start, whether it applies to existing users and its author.
    Saving first reads OpenRouter's public model list, `https://openrouter.ai/api/v1/models`, the one request the web makes outside Supabase: a model must take image input and support structured outputs, the eval's rule, or it is not saved, and none is while the list cannot be read. The server checks the role, the terms, the start and the favour, and records the version ([ADR 0071](adr/0071-give-each-user-a-plan-whose-model-and-daily-limit-an-admin-sets-in-the-database-and-make-one-model-call-per-photo.md)).
  - **프롬프트** (`/admin/prompts`): the extraction prompt's versions ([ADR 0073](adr/0073-keep-the-extraction-prompt-as-append-only-versions-in-the-database-served-by-an-active-and-an-admin-only-test-label-and-record-what-served-each-call.md), [`server.md`](server.md) §Prompt store):
    - "사진 한 장으로 시험", which names the version it runs, the test version while one is set and the active one otherwise. It runs `extract-cards` on one photo as the admin and lists the cards, or says why there are none, and the photo counts against the admin's own daily limit. The browser first turns the photo upright and scales it as the app does, a JPEG with its long side at most 2048 px, stepping its quality down until it is at most 900,000 bytes, under a Server Action's default 1 MB body;
    - "새 버전", a form that saves the text with a note as a new version, starting from the active version or from the one the address's `from` names, and opens it. Saving serves it to no one;
    - "저장된 버전", newest first, each with its labels 사용 중 and 테스트, note, length, time and author.
    - `/admin/prompts/[id]` shows a version's text and, unless it is active, its lines against the active version, each changed line marked − or + and named "뺌" or "더함" for a screen reader, with "모든 사용자에게 적용", "관리자만 테스트" while it is neither, "테스트 끝내기" while it is the test version, and "이 버전에서 새 버전 쓰기". An id that is no version's is not found.
  - **관리자** (`/admin/admins`): the admins, earliest granted first, with who granted each and when, "해제" on every one but the signed-in admin's own, marked "(나)", and the form "관리자 지정" by an existing user's email.
  - **작업 기록** (`/admin/audit`): the latest 100 admin writes, newest first, each its action, target (linked when it is a deck or a user), time and admin.
- Every action asks first: its button opens a group named by the question, with "취소" and, last, its confirm button, focused, in the navy fill; the one action that cannot be undone, 공유에서 영구 삭제, confirms with "영구 삭제" as a red final button, `dont-know-text` under `on-dont-know-text`, as `design.md` §Principles 5 draws an irreversible action's last step (#280); once confirmed, the Server Action in `admin`'s `actions.ts` calls the server, returns the sentence a `status` region shows, and revalidates `/admin`. The actions are 숨기기, 숨김 해제, 비공개로 전환, 신고 정리 and 공유에서 영구 삭제 on a deck, 이용 정지 and 정지 해제 on a user, 모든 사용자에게 적용, 관리자만 테스트 and 테스트 끝내기 on a prompt version, and 해제 on an admin; the prompt form and the trial submit as forms; the two that take a reason open a field for it first, and confirm only once it holds one; the grant form submits through `useActionState`. A refusal returns "관리자만 할 수 있어요." and changes nothing.
- The `admin` feature holds the reads (`read-admin.ts`), each row parsed at the boundary and a failure returned as a value, the Server Actions, one `<verb>-<noun>.ts` file each (`hide-deck.ts`, `unhide-deck.ts`, `unpublish-deck.ts`, `dismiss-reports.ts`, `grant-admin.ts`, `revoke-admin.ts`, `create-plan-version.ts`, `grant-plan.ts`, `revoke-plan.ts`, `suspend-user.ts`, `unsuspend-user.ts`, `remove-deck.ts`, `save-prompt.ts`, `activate-prompt.ts`, `test-prompt.ts`, `clear-test-prompt.ts`, `try-prompt.ts`, and `find-users.ts` for the search as one types) over the shared call and refusal in `action-call.ts`, which reads a deck's id through `decks`' `parseDeckId` and a user's through its own `parseUserId`, refusing any other as malformed without asking the server, as the routes' pages answer not found, re-exported by `actions.ts`, and the components; the routes' `_components/content.tsx` composes them. Times show in the cookie's zone.

### Tests

Each line names a file and what it covers; the file holds the cases.

- `web/src/app/(shell)/admin/__tests__/admin.test.tsx` — the area against the server's admin functions, substituted by `web/src/testing/mocks/admin.ts`, which answers for an admin and refuses anyone else with `42501`: the gate, each section, each action asked first and refused to a user who is not an admin, the plans with their versions, a new version from now or a later day and its refusals, Max granted, with OpenRouter's model list substituted, and the audit log.
- `web/src/app/(shell)/admin/__tests__/overview-heading.test.tsx` — the overview's heading, the menu's name for it.
- `web/src/app/(shell)/admin/__tests__/prompts.test.tsx` — the prompts pages with `extract-cards` substituted and the browser's downscale passed through: saving, the diff, the labels, the trial and their refusals.
- `web/src/features/admin/__tests__/usage.test.ts` — the usage the overview charts; `usage-charts.test.tsx` — the charts, given a size as jsdom lays nothing out, with their named image and patterns.
- `web/src/features/admin/__tests__/prompt-diff.test.ts` — the line diff.
- `web/src/features/admin/__tests__/client-boundary.test.ts` — every module of the area without `"use client"` imports only components from a client module, since on the server a client module's export can be rendered but not called (#473).
